# Crystal Clicker

スマートフォン向けクリッカーゲーム。HTML/CSS/JS の単一ファイルで動作し、サーバー不要でブラウザだけで遊べます。

## 遊び方

`index.html` をブラウザで開くだけで起動します。

クリスタルをタップしてクリスタルを集め、アップグレードや自動生成ユニットを購入して生産を拡大していきます。

## 主な機能

### コアシステム
- **タップ** - クリスタルをタップして資源を獲得
- **タップ強化** - 6 種類のアップグレードでタップ威力を強化 (Sharp Finger ~ Cosmic Blow)
- **自動生成ユニット** - 8 種類のジェネレータが毎秒クリスタルを自動生産 (Auto Cursor ~ Nebula Core)
- **アンロック** - 累計獲得量に応じて上位アップグレードが段階的に解放

### プレステージ (転生)
- 累計 100 万クリスタル到達で「星」を獲得してリセット
- 星ごとに全生産 +5% の永続ボーナス
- 8 種類の星アップグレード (タップ倍率、自動倍率、コスト削減、オフライン倍率など)

### セーブ / ロード
- `localStorage` に 30 秒ごとの自動セーブ
- 手動セーブ、Base64 エクスポート / インポート
- ページを閉じる際にも自動保存

### オフライン報酬
- 離脱中に CPS の 50% を自動獲得 (最大 24 時間)
- プレステージ強化でオフライン倍率アップ可能
- 復帰時にモーダルで獲得量を表示

### 実績
- 21 種類の実績 (タップ回数・累計獲得・CPS・プレステージ回数など)
- 解除時にクリスタル報酬とトースト通知

### 演出
- パーティクルエフェクト、フロートテキスト
- Web Audio API による効果音 (設定で ON/OFF 可)
- タップ時のクリスタルアニメーション

## 技術仕様

| 項目 | 内容 |
|------|------|
| 構成 | 単一 HTML ファイル (外部依存なし) |
| 対応ブラウザ | モダンブラウザ (Chrome, Safari, Firefox, Edge) |
| モバイル最適化 | `viewport-fit=cover`, `safe-area-inset` 対応 |
| データ保存 | `localStorage` |
| 音声 | Web Audio API |
